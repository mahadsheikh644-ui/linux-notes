(with automation, containers, monitoring, cloud later).

- `01-storage/` — LVM, RAID, backups
- `02-services/` — systemd, cron, logs
- `03-network/` — ip, SSH, firewalls, DNS
- `04-automation/` — Ansible, Docker, CI/CD
- `05-monitoring/` — Prometheus, Grafana
- `06-cloud/` — AWS/Azure
- `07-projects/` — portfolio projects
- `labs/` — homework labs + my solutions
- `cheatsheets/` — one-page command references
